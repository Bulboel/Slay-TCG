Publier les histoires dans le jeu

1. Exporte tous les textes : tu obtiens card-lore.json.
2. Ouvre le dossier des données sur GitHub, dépose ce fichier et valide avec « Commit changes ».
3. Après le déploiement, les histoires sont visibles pour tous les joueurs.

Tu peux aussi me transmettre ce seul fichier pour que je publie tout ensemble. Pour retrouver tes brouillons sur un autre appareil, exporte-les puis importe le fichier ici.
